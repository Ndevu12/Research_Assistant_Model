# Setup System

Documentation for the setup modules (`health_check`, `manager`, `ollama`, `setup`) has moved to the docs site:

**[Setup System — full reference](https://ndevu12.github.io/Research_Assistant_Model/setup-system/)**

Quick commands (use Pipenv from the project root):

```bash
pipenv run python -m setups.health_check
pipenv run python -m setups.manager
pipenv run python -m setups.manager --model llama3.1:8b
```

See also: [Health check](https://ndevu12.github.io/Research_Assistant_Model/getting-started/health-check/) and [Troubleshooting](https://ndevu12.github.io/Research_Assistant_Model/operations/troubleshooting/).
